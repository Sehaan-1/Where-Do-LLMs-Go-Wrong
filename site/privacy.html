Privacy on this site.

This is a static project information site. It has no account system, annotation submission, or contact form.

Last reviewed: 21 October 2026.

Cookies and tracking

This site does not set or read cookies, use analytics, advertising pixels, or fingerprinting, or store values in browser storage. The page has no cookie-consent banner because it uses no site cookies or tracking technologies. The step and workflow previews change in-memory page content only.

Information the page collects

The page code does not ask for personal information. It has no contact form, account system, or annotation submission. No annotation decisions are submitted or saved.

The site loads its styles and script from this project only. It uses no remote fonts, image hosts, third-party embeds, analytics endpoints, or other external resources. A Content Security Policy also blocks cross-origin subresource connections and form submissions from the page.

Hosting and external links

The static hosting provider may process ordinary request metadata, such as an IP address, requested file, user-agent, and request time, in its server logs. The project does not control the provider’s retention or security practices; consult the policy of the host you use to serve this site.

Links to GitHub are ordinary links, not embedded content. Following one takes you to GitHub, which processes information under its own policies and terms.

Annotation records

Human annotation is a separate, optional Label Studio workflow operated by the research team. This website does not receive Label Studio exports or annotator information. For that workflow, use pseudonymous annotator IDs, keep raw exports in access-controlled storage, and follow the repository’s annotation runbook and applicable institutional requirements.

Contact and local requirements

The project repository is the contact point for questions about this site: contact the project through GitHub issues. No personal address, email, or separate business identity is represented here.

This notice describes the current site implementation; it is not legal advice or a guarantee of compliance in every jurisdiction. The person or organization deploying the site should review the rules that apply to that deployment.
