Read the limits first.

This seed supports tooling and a small annotation pilot. It is not a current-model benchmark or a completed study.

  • Historical traces

    Released `6b_finetuning` and `175b_finetuning` GSM8K traces; no new model generations.

  • No step labels yet

    Upstream `answer_correct` is source metadata, not a human step judgment.

  • Line-based units

    Non-empty newlines are practical annotation units, not guaranteed semantic steps.

  • Benchmark overlap

    GSM8K is public and may overlap model training data; broad capability claims are out of scope.

Questions before reuse.

Answers are limited to what the repository and current seed actually establish.

Has the seed been human-annotated?

No. The batch has no human step labels; no Cohen’s kappa or first-error findings are reported.

Which model outputs are included?

Historical GSM8K release traces under `6b_finetuning` and `175b_finetuning`, sampled from a pinned source revision. They are not fresh generations and are not representative of current models.

Does this page collect annotation decisions?

No. The sample controls are read-only previews. Actual annotation uses the separate Label Studio workflow described in the runbook.

How can I reproduce the seed?

Use the pinned GSM8K revision, manifest, and offline preparation command in the repository README. The project makes no implicit network calls to model providers.
